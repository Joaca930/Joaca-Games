Entrar com o GitHub

Use o token da conta dona do repositório. Ele fica na memória desta aba enquanto você estiver conectado.

Como criar meu token?

No GitHub, abra sua foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Gere um token com prazo de validade, selecione apenas o repositório do site e dê a Contents a permissão Read and write. Cole o token acima apenas na sua cópia do site.
